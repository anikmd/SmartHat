# Code of Conduct

## Our standard

We want SmartHat to remain a respectful and constructive project. Participants are expected to communicate professionally, welcome good-faith feedback, and focus criticism on the work rather than people.

## Unacceptable behavior

Harassment, discrimination, personal attacks, threats, deliberate disruption, and sharing another person's private information without permission are not acceptable.

## Enforcement

Project maintainers may remove comments, close discussions, or restrict participation when behavior violates this code of conduct.

For sensitive concerns, contact the repository maintainers privately through the contact method listed in the repository profile.
