# Security Policy

## Scope

SmartHat is an academic hardware prototype. Security reports concerning the repository, firmware, or documentation are welcome.

## Reporting a concern

Please do not publish credentials, private contact information, SIM details, or other sensitive material in a public issue. Contact the maintainers through the contact information associated with the repository and provide enough detail to reproduce the issue safely.

## Prototype safety

Never test crash-detection or electrical changes on a moving motorcycle or in a way that could endanger a rider. Validate changes on a controlled bench setup first.
